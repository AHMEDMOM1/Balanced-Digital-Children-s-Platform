# Implementation Plan: Initial Content Seed

**Branch**: `010-content-seed-initial` | **Date**: 2026-06-10 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/010-content-seed-initial/spec.md`

## Summary

Inserts a representative batch of 10 content items (3 videos, 3 stories, 2 activities, 2 games) and 3 category rows into the existing Supabase database. A TypeScript seed script runs via `npm run seed:content`, checks for existing rows by `(title, type)` before inserting, and prints an inserted/skipped/failed summary. A Jest integration test provides the TDD gate: it fails before seeding and passes after.

## Technical Context

**Language/Version**: TypeScript 5.9 (ts-node ESM, consistent with existing scripts)

**Primary Dependencies**: `@supabase/supabase-js` ^2.x (already installed), `ts-node` (already installed)

**Storage**: Supabase PostgreSQL — `content_items` + `categories` tables (schema from feature 009, no changes)

**Testing**: Jest 29 + `ts-jest` (integration project, same config as `tests/integration/contentSchema.test.ts`)

**Target Platform**: Node.js (seed script), React Native app (displays seeded content)

**Project Type**: CLI seed script + integration tests

**Performance Goals**: Seed script completes < 30 seconds for 10 items + 3 categories

**Constraints**: Idempotent (skip not upsert), no Supabase Storage uploads, CDN image URLs only

**Scale/Scope**: 10 content items + 3 categories initial batch

## Implementation Phases

### Phase 1 (TDD Gate) — Write test first, confirm FAIL
- Write `tests/integration/contentSeed.test.ts`
- Assert: ≥3 videos, ≥3 stories, ≥2 activities, ≥2 games, ≥3 categories
- Assert: counting game config has `type`, `question`, `image_url`, `correct_answer`, `choices`
- Assert: matching game config has `type` and `pairs` array with ≥2 items
- Run test → expect FAIL (0 rows)

### Phase 2 — Implement seed script
- Create `scripts/seed-content.ts`
- Define seed data arrays inline (SEED_CATEGORIES, SEED_ITEMS)
- `loadEnv()` → validate credentials → create Supabase client
- `seedCategory(client, cat)` → SELECT by name → skip or INSERT → return status
- `seedContentItem(client, item)` → SELECT by (title, type) → skip or INSERT → return status
- Collect all results, continue on individual error, exit 1 if any failures
- Wire `npm run seed:content` and `npm run test:content-seed` in package.json

### Phase 3 — Run seed, confirm PASS
- Run `npm run seed:content` → verify 10 inserted, 0 skipped, 0 failed
- Run `npm run test:content-seed` → all tests pass
- Re-run seed → verify 0 inserted, all skipped, exit 0
