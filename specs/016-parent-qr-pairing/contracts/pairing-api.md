# Contract: Pairing Service API

**Module**: `services/api/pairing.ts`  
**Spec**: 016-parent-qr-pairing | **Date**: 2026-06-11

---

## Overview

The pairing service exposes two functions used by the `qr-pairing.tsx` screen:
1. `generatePairingToken` — creates a new invitation in the database and returns the display data
2. `watchForChildPaired` — subscribes to database changes and calls a callback when a child device uses the token

All Supabase calls are encapsulated here (no `supabase.from()` in screen components — constitution §API Hook Pattern).

---

## Function: `generatePairingToken`

```typescript
export async function generatePairingToken(
  familyId: string,
  supabase?: SupabaseClient
): Promise<PairingResult>
```

**Behaviour**:
1. INSERT a row into `pairing_tokens` with:
   - `family_id = familyId`
   - `token` = generated by `gen_random_uuid()` (DB default)
   - `manual_code` = 6-digit code generated by DB default expression
   - `expires_at` = `now() + INTERVAL '10 minutes'` (DB default)
2. Return the inserted row mapped to `PairingResult`:
   - `token`: the full `PairingToken` object
   - `displayCode`: `manual_code` formatted as `"XXX-XXX"` (hyphen at position 3)
   - `error`: null on success, non-null error message on failure

**Structured log** (per constitution §V):
```json
{ "level": "info|error", "hook": "generatePairingToken", "family_id": "...", "duration_ms": 123, "error": null }
```

**Error mapping**:
- `42501` (RLS violation) → `"Unauthorized — parent session required"`
- Network timeout → `"A network error occurred. Please try again."`

## Function: `watchForChildPaired`

```typescript
export function watchForChildPaired(
  familyId: string,
  onPaired: (childId: string) => void,
  supabase?: SupabaseClient
): () => void   // returns unsubscribe function
```

**Behaviour**:
1. Subscribe to Supabase Postgres Changes on `public.pairing_tokens`:
   - `event: 'UPDATE'`
   - `filter: 'family_id=eq.' + familyId`
2. On each UPDATE event: if `payload.new.used_at !== null && payload.new.child_id !== null`, call `onPaired(payload.new.child_id)`.
3. Return an unsubscribe function that calls `supabase.removeChannel(channel)`.

**Lifecycle requirement** (constitution §API Hook Pattern):
- The unsubscribe function MUST be called in the `useEffect` cleanup of `qr-pairing.tsx`.
- Subscription lifecycle events (subscribe, disconnect, reconnect) MUST be logged.

**Structured log**:
```json
{ "level": "info", "hook": "watchForChildPaired:subscribed", "family_id": "..." }
{ "level": "info", "hook": "watchForChildPaired:paired", "family_id": "...", "child_id": "..." }
{ "level": "info", "hook": "watchForChildPaired:reconnected", "family_id": "..." }
{ "level": "warn", "hook": "watchForChildPaired:closed", "family_id": "..." }
```

## Screen Contract: `app/auth/qr-pairing.tsx`

### Props / Route Params
None. `family_id` is read from `useAuthStore` (available after OTP verification creates the parent session).

### State
| Name | Type | Description |
|------|------|-------------|
| `pairingResult` | `PairingResult \| null` | Current token data; null while loading |
| `isGenerating` | `boolean` | True while `generatePairingToken` is in flight |
| `remainingSeconds` | `number` | Countdown, updated every second |
| `error` | `string \| null` | Non-null if token generation fails |

### Behaviour

**On mount**:
1. Call `generatePairingToken(familyId)` → set `pairingResult`, start countdown.
2. Call `watchForChildPaired(familyId, onPaired)` → store unsubscribe fn.

**Countdown timer** (`useEffect`, interval 1000ms):
- `remainingSeconds = Math.max(0, Math.floor((new Date(pairingResult.token.expires_at).getTime() - Date.now()) / 1000))`
- When `remainingSeconds === 0`: call `handleRegenerate()`.

**`handleRegenerate()`**:
1. Set `isGenerating = true`.
2. Call `generatePairingToken(familyId)`.
3. On success: update `pairingResult`, reset countdown, set `isGenerating = false`.
4. On error: set `error`, set `isGenerating = false`.

**`onPaired(childId)`**:
- Unsubscribe from realtime channel.
- Navigate to `/(parent)` via `router.replace('/(parent)')`.

**On unmount** (`useEffect` cleanup):
- Clear countdown interval.
- Call unsubscribe function from `watchForChildPaired`.

### UI Elements

| Element | Condition | Behaviour |
|---------|-----------|-----------|
| QR code (SVG) | `!isGenerating && pairingResult` | Encodes `JSON.stringify({ token, family_id, expires_at })` |
| Manual code text | Always | Shows `pairingResult.displayCode` or `"---"` while loading |
| Countdown text | Always | `MM:SS` format; shows `"--:--"` while `isGenerating` |
| Regenerate button | Always | Disabled + shows `ActivityIndicator` when `isGenerating` |
| Error banner | `error !== null` | Shows error message with retry CTA |
