## Summary

Implement a robust resilience layer to handle offline states, session persistence, secure PIN recovery, and performance adaptation on low-end devices. The technical approach involves local caching (up to 100MB), server-authoritative time enforcement, and real-time connectivity adaptation (battery saver mode).

## Technical Context

**Language/Version**: TypeScript / React Native (Expo)

**Primary Dependencies**: React Native, Expo, Supabase, @react-native-community/netinfo, expo-battery, expo-sqlite, expo-file-system

**Storage**: Supabase (Remote), Local Cache using expo-sqlite (100MB limit with LRU)

**Testing**: Jest (Unit/Integration), Detox (E2E with real-device farm)

**Target Platform**: iOS and Android

**Project Type**: mobile-app

**Performance Goals**: 
- Cold start < 3s (SC-001)
- Session timer accuracy within 5s across restarts (SC-002)
- Offline indicator detection < 5s (SC-003)
- Animation degradation detection < 500ms (SC-008)

**Constraints**: 
- Cache: 7 days or 100MB (FR-001)
- PIN Recovery: 3 attempts/hr, 24h cooldown (FR-005)
- Server-authoritative time (FR-006)
- Battery saver reconnection: 15s interval (FR-008)

**Scale/Scope**: 5 key screens for accessibility, cross-platform iOS/Android resilience.
