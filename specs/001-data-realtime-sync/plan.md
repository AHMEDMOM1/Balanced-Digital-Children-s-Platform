# Implementation Plan: Real Data Layer & Realtime Parent-Child Sync

**Branch**: `006-resilience-testing` | **Date**: 2026-06-09 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `/specs/001-data-realtime-sync/spec.md`

## Summary

Replace all mock content arrays with Supabase-backed data filtered per child profile and parent-blocked categories (opt-out), and enable a bi-directional realtime command channel using Supabase Broadcast backed by a durable `realtime_commands` table for offline replay. All API access is encapsulated in `services/api/*.ts` hooks returning `ApiResponse<T>`; realtime subscriptions live in `services/realtime/familyChannel.ts`. Session lifecycle follows `active → paused ↔ active → ended`. COPPA + GDPR-K constraints apply: activity logs purge after 90 days, no behavioral profiling, no third-party data sharing.

## Technical Context

**Language/Version**: TypeScript 5.9 / React Native 0.83.6 (Expo SDK 55)

**Primary Dependencies**:
- `@supabase/supabase-js` v2 — backend client (auth, database, realtime)
- `zustand` v5 — client-side session and auth state
- `expo-sqlite` — local offline cache (structured SQL on device)
- `@react-native-async-storage/async-storage` — lightweight key-value persistence
- `@react-native-community/netinfo` — network state detection
- `react-native-reanimated` v4 — animation (pause overlay, exit animations)
- `victory-native` — charts (Phase 3, referenced for type completeness)

**Storage**:
- Remote: Supabase Postgres with RLS
- Local: expo-sqlite (offline content cache + command queue)

**Testing**:
- `jest` — unit + integration tests (`npm run test`)
- `detox` — E2E tests (`npm run test:e2e`)

**Target Platform**: iOS 15+, Android 10+ (Expo managed workflow)

**Project Type**: mobile-app (React Native / Expo Router file-based navigation)

**Performance Goals**:
- Content list load < 1 second on repeat visit (cached)
- Parent command (pause/category block) reflected on child device < 2 seconds
- App launch with no network < 3 seconds showing cached content

**Constraints**:
- Offline-capable: cached content + server-authoritative time, never device clock
- COPPA + GDPR-K: 90-day log retention, no behavioral profiling, no third-party data
- RTL layout support for Arabic-speaking target market
- Command queue: max 50 commands on-device; discard entries older than 24 hours on reconnect
- Session states: `active` → `paused` ↔ `active` → `ended` (terminal)
- Category blocking: immediate stop (not finish-current-item) + exit animation

**Scale/Scope**: Family-sized (1–5 children per parent account); global, Arabic-speaking market focus
